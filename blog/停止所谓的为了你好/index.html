停止所谓的“为了你好”

丢掉、丢掉、再丢掉

以前，我跟一些朋友还有联系时，就经常会“送”别人一些有的没的的东西： - 明信片，工具，软件，甚至某些“积极”的想法，“有用”的内容 - 可能是别人告知了“谢谢我不喝”，但我还是给他预留了一杯奶茶 - 是别人声称要减肥，我却说你不胖，太瘦了，不用减

“送”往往被美化，而不好听的另一边，这叫做“强迫（Force）”：如果我送了，那你就必须接受。

但问题是，自己却从来没思考过，这些东西到底是不是别人真的需要的，至少思考一下别人拒绝时是否肩上背负压力。

令人不适的经历是一面镜子，在自己感受到不适的同时，也明白自己长什么模样。

  • 秋天时，跟家里人出门买衣服，我看上一条裤子，重量和质感都到位，但不足的是只有松紧带，没有腰带设计。询问价格，这条裤子350R，几乎是立刻，我认为这条裤子的售价与价值不匹配。我说算了，不要了。家人在身边说：没事的，要是你喜欢，这次买了就买了。我说：这不是钱的问题。接下来的第二天，她又过来问：要不要出门，那条裤子要不还是给你买了吧。第三天，这个问题又重复了一遍。我说这条裤子不值得，但一直到现在，他们都以为这是我给不舍得打的借口，觉得我需要这条裤子

  • 学期中，家里人总是会寄来各种各样的快递。而我在想办法，从咸鱼的垃圾堆里淘点电子垃圾出来，更换一下我的设备。这些快递的价格都不小，但是又奇奇怪怪。贵的有衣服，但显然家人的衣物审美和我并不在一个世界里。于是这些花大价钱的衣服都闲置了。剩下的，是一些有的没的零食，可是一来我要减肥不吃零食，二来这些零食的质量真是差的惊人，已经到了我担心吃下会导致身体出问题的级别。每次这种快递的价格都来到200R。天，如果这些浪费的钱都给我，我可能已经换上自己想要的东西了。

最糟糕的不止于此，更难以挣脱的是：你无法和别人沟通。自己与长辈的相处循环是这样的：他们买了快递 -> 你必须收 -> 你向他们温和解释，这些东西你不要，下次别买 -> 他们认为你在客气，继续压缩你的底线 -> 下次寄来了更多快递 -> 你和他们大吵一架 -> 他们才能听进去一点，部分是赌气因素，暂时不买了，同时认为自己受了委屈，好心当成驴肝肺 -> 时间久了，再买快递，就赌你会收，如果你收了，那么就继续买。一遍又一遍地循环。

原来历史竟然惊人的相似，我之前做的，和被对待的，其实根本没有差异对吧。没有经历过强制被给予，尤其还是自己不想要的东西时，那种厌烦感是挡不住的。就算你强忍者收下来，处理这种东西都会磨损掉你的心情和精力。

大学几年，自己的朋友慢慢逐渐走远，一个个好朋友被自己聊崩。不再找理由，确实是我做错了。

你觉得好的，不是别人想要的。可以给，但至少附上可以拒绝的选项。 点奶茶，你可以自己提前买个小杯。如果对方是真的不喝，那你就处理掉多的。如果只是客气推辞，那皆大欢喜，不浪费，也踩中点。 软件也是，你尽管做，但别顾虑这到底是否会被收下。不要给东西附上这种：这是专门为你做的捆绑销售。 朋友说减肥，可能是真觉得自己胖了要减。此时送零食，只是在阻碍人家推进计划。无论是他没有控制住自己吃了，还是把这些零食想办法分发给别人处理掉，都只是单纯地给人增添麻烦。 征求意见至多问两遍大概也足够了，第二遍仅仅用于确认，不是还留有不切实际的期待，别一直问到对方拿你没辙而接受。

不做边界处理，偶尔一次会。别人觉得你很有心意，时间长了只让人觉得喘不过气。初心是好的，我知道初心是好的。但单单初心，无法给不当操作留下一个妥善的交代，别再“为了你好”。
