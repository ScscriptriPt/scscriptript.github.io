风口还是赌博

当你在某个方面投入了很多，或者客观上不算很多，但是主观上已经投入了很多时，这些沉默成本你还有勇气收回来吗？

常说站在风口上，猪也能起飞。你可以确定自己走在风口，还是自顾自做了一场没来由的赌博呢？

01-从苏州到合肥——苏大与合工大¶

2024 年，我在苏州高中毕业，高考 635 分，这个分数在当时可以报考苏州大学，除临床医学之外的任何专业。

但是我没有选苏大，听了 “ 专业 > 城市 > 院校层级 ” 不等式，转而报考了合工大的集成电路设计创新实验班。

合工大的集电专业当时鼓吹下，风头无量，吸引了超大批人争相报考。于是我没报上，转而来到了电子信息工程（EE）。也不算太差，毕竟是热门带电工科。

从这一小件事情就不难看出，我做事几乎没有脑子：

  • 没有实际数据考证
  • 没有了解过合肥的城市状态，企业构成
  • 没有了解过专业要学的內容
  • 没了解过有哪些岗位可以就业
  • 没有想过退路

贸然选择了合工大，做出这个决定，背后的驱动仅仅是摸不着到的“舆论”：

  • 合肥是众多城市中发展速度最快的一个
  • 合肥是科创之城
  • 合工大是机械四小龙
  • 合工大是安徽仅次于中科大的第一院校，认可度非常高
  • 合工大的食堂很好

这一小件事情背后体现的，我从来没有深思熟虑的问题，也为各种“作死”事件埋下伏笔。离开了苏州，这让我缺少了太多太多可能的实习机会。

但我不盲目黑啊，上述內容里，合工大的食堂很好是真的。

02-硬件的 PTSD¶

大一刚入学，什么都想学。嵌入式是最典型的一个，当时AI还没有这么发达，Agent更是还没出现。每个接触过电子的人都绕不开四个杀手：

  • Keil5
  • STM32CubeMX
  • STC89C52RC
  • STM32F103C8T6

为了参加校园内的 robomaster 战队还有电子信息创新基地（电创），內容主要就是学单片机，没接触过 stm32cubemx，一直和 Keil5 硬刚。只要你用过这些东西，绝对理解我在说什么，这些东西真是刀刀致命。

后来两个地方都没进去。因为对驱动、系统，很多內容不了解，整个不知道自己错在哪里了的奇怪硬件环境，给我套上了一层硬件 PTSD。

在大一的第二个学期，跟着朋友报了一个网络安全的培训机构课程。

算上考 CISP-PTE，还有酒店的费用，约用了 27,000。

当时听着朋友的推荐，还有培训机构老师的说明，觉得这里很好，但是真是属于不知道干什么，走一步算一步的病急乱投医。

这时候觉得学习传统的渗透测试还有蓝队技能，会拿到一份比较好的工作，灾难就要开始了。

03-你终于上当了¶

这里再说明，学网安又不转专业带来了哪些问题

我在开始学习网安时，已经是大二第二学期，到大二第一学期，学院有最后一次转专业的机会，我没有转专业。

所以，我实际上本科专业仍然是电子信息，但是自己已经基本不学硬件的相关內容了，很大部分的时候都投在网络安全上。

可是，我的水平、热爱、毅力，很明显比不上这些又有天赋又卷的人，南信大，江海大，还有大专的学生。

即便不是这些学校的学生，就跟同校的学生比，电子信息的课程容量也是独一档的大。作这篇文章时，我在大三第一学期，这时候我的课程量甚至比同实验室大二信安同学还要多。

于此同时，当我发现自己完全跟不上培训机构设立的课程节奏，并且完全听不懂课程里面的內容在说什么的时候。我开始试着问 AI，问朋友，这个课程的情况怎么样。得到的回复是：这个课程的內容深度浅，并且推进速度完全不正常。

另外，课程还有别的问题，就在我上一篇所写的“安全的未来在哪里”那篇文章中，这些问题，机构的课程一个都没拉下，真是切实踩中了所有认知的雷点，我根本学不了。

04-赛博朋克的未来已来¶

我大二第二学期加入了学校的网安实验室，找到了一起学习的人，也有了自己的工位。这一段时间，可能说是忙忙碌碌，学到了不少，但是更多的是无头苍蝇乱转。

于此同时，2026 年是每个人都会铭记的年份，这一年 Agent 彻底来了。

Agent 解决大部分砖头代码问题，所以第一刀先砍死了大部分前端；

接着来到安全，CTF 首当其冲。所有人都使用 Agent 解题。 CTF 又因为 Agent 要升级赛题难度，人工打不出来又要用 Agent 做，恶行循环。而顶级大赛又过于困难，根本就拿不到名次，训练了大半天，最后其实也没有用。一直到 CTF 在企业招聘的加分项中形同虚设。

Agent 不断进化，接下来侵蚀后端的岗位，以及大量原本是人工劳动力负责的安全巡检全部由 Agent 自动化完成，安全的低端岗位大幅消失。

再接着，Agent 挖洞盛行，每天每天，各种漏洞登上互联网头条，以及各大 Agent 渗透项目，各种奇怪的同质主从架构渗透 Agent 工具开发。

于此同时，我在干什么？我没有乘上第一波使用 Agent 的潮流。在实验室的同学都开始大幅度使用 Claude Code、Codex 时，我还在传统 chat，最多用例如 Trae。

我还在学传统的所谓“红队思维”，学 HackTheBox，打靶机。但是又没有挖漏洞，自己也很难坚持挖出什么东西出来。就算我有全流程综合渗透的能力，没有漏洞在 HR 眼里直接就被判死刑了，我连实习都找不到。

这不是坏菜了吗？

05-两头不是人¶

场面变得更加糟糕：我为了学渗透，觉得自己转了方向，就不再想学原来的硬件相关內容了。于是，我本科的绩点一落千丈。但是另一边我的渗透也没学好，找个低端岗也更是找不到。于是局面就是：两头不是人。

去硬件厂商，不要我，去安全厂商，也不要我。考研么，我觉得我的心态不足以支撑我度过备考和读研的全部历程。备考本身就很恐怖了，考不上那就更恐怖了，考上了要读三年那就更更恐怖了！

以我的心态，很可能在硕士二年级就跳了，我还是尽量别冒这个风险了吧。

06-死透的行业¶

死透的行业不是说行业不存在了，而是对于入门的大多数人来说，再也不友好了。我们为了争到一口饭吃，拼的头破血流，哪怕这口饭并不好吃。

我这样简单地（或者说很幼稚地）理想化正常行业长什么样：

  • 门槛性：入门有技术门槛，有竞争
  • 长周期：学习三年多积累经验都很正常
  • 有成长机会：找实习多投数份，薪资不高。最起码企业有培养新人的想法，给实习的机会，不死抓即插即用
  • 有未来可见性：经过竞争能够找到一份岗位

简单来讲，这是一个难度、需求、培养多方面平衡之后的结果，一旦有哪一项甚至多项与其他项不匹配，事情就开始变得糟糕。这里的培养是上面的成长机会与未来可见性的抽象综合，并非专指企业或机构提供的培训课程，短期培养出一个人才的培养。

但是很显然，网络安全逐渐已经开始脱离这些基准线，缺少培养，但高难度，高需求。“网络安全人才需求突破 480 万”，是横在每个网安人头上的一次大型 “西线无战事”。

企业需要的是能严判、溯源、渗透、取证、逆向、抗事的人才。不仅国内，这类人才在国外也极稀缺，自然培养周期也极长。于此同时，你不能假设天才遍地：他们有强大的自学能力，你只需要从现有的人中挑选即可，这种想法是不现实的。

但企业没有培养的意图，这是被经济一肘导致的应激反应。培养一个人的成本极高，并且不能保证培养后这个人仍然留在这里工作，他可能带着一身能力跳槽到更高薪水的岗位。此时你还要花更高的薪水招一个同样能力的人填补这个岗位，那么谁来？于是每家都想要即插即用，可哪里有这么多人呢？

IC 设计、车辆、车联网、物联网都是这样，企业挥舞着钞票，JD 信息在招聘网站上铺天盖地，却根本找不到人应聘。

这些要求动辄三到五年经验，而车联网概念本身火起来也才没几年，光是学习需要的信息极其闭塞在企业内部，资料非常难找。若是在各种平台上面想要寻找相关的资料，近乎一片荒漠。就单单论 CAN 总线这么一个任何入行车联网的人都应该了解的內容，你随手捏一把学生，连这个概念都没有听说过。更别提学校的课程能和企业接轨了，此时也没有任何培养。

07-引入变量-培训机构¶

并且这还不是最糟糕的，此时我们还要引入一个新搅局变量：培训机构。

我从前听说过一个论调：“计算机行业为什么卷，就是开源害的。你把自己知道的东西都公布出来，所以大家都会了，那么你就没饭吃。”

在我第一次听到这句话时，我没有认为它错，但感觉上有很大部分不对劲。不是说这句话说的很冲让人体感不舒服，而是逻辑上有地方存在缺陷，只是我一直都没想对劲。那么让计算机越来越红海的是什么？

不，不是自己人开源，而是供需开始变得不对等。开源从计算机诞生开始，就一直存在。

国内互联网真正腾飞的时间点是 2009 年，在这之后，全部行业开始极其激进的数字化时代，大量程序员不断涌入这个行业，而需求实在是太大了，政府、企业、银行、学校等等，几乎社会的上上下下全都需要 IT 建设。当时的企业是真的敢砸下长达半年的时间，疯狂培养一些能够工作的程序员。因为今天培养他们的成本，明天就要靠新的项目把血收回来。

大部分 IT 从业人员骨子里有一种对于技术的追求，他们考虑自己的薪资，生活水平，但在这之外，更加重视自己的工作能否带来什么。排除极小部分坚持闭源主义的IT人士例如比尔盖茨，大部分 IT 人都有开放自身知识的倾向。我们把所有知道的事情拼命地告诉后辈，告诉你有这么多有用的知识供你学习。《流畅的Python》、《汽车黑客手册》、《Python黑帽子-渗透测试编程之道》以及数不胜数的经典书籍，作者是为了靠卖这一本书发财吗？显然不是。

多年以后，我会回忆起那个遥远的签下培训合同的下午，我想我现在想明白了一些事情：当一个行业开始越来越多培训的时候，就该跑了。

我一直秉持着一个观点为书本是承载知识的最好媒介，后来接触了IT后，我可以转换一下：文档是承载知识的最好媒介。（不包含实操性技能的学习）

因为明明高质量的教材遍地都是，在网上随手搜：

  • 一本教材，认真学完
  • 一本习题册，认真刷完
  • 一个靶场，认真打完
  • 一次项目，认真做完

这些事情任意一项都能使人受益匪浅，但高考教培、考研、考公、副业、计算机、嵌入式、网络安全，为何培训依旧大行其道，让很多人中招？

这件事情不能说客户完全没错，具体来说错在没有对自己负责。一般来说用户会有包括并且可能不限于以下的问题：

  • 想要走捷径
  • 搜集资料能力太过薄弱
  • 心理安慰

于是培训机构向他们承诺一个虚假的未来，晒出很多取得大厂offer的学员作为典例。然而太多的培训代表了两件事情：

  • 知识体系开始趋于成熟，缺少差异化
  • 这项技能本身开始变得不值钱，培训收割反而更赚钱

如果有金山，那么直接挖就好了，而只有在虚假的淘金热中才需要卖铲子。并且如果是重实践的內容，光看课程也什么都学不会。

IC设计、车联网、物联网怎么没那么多培训班呢？因为这些行业的体系本身就不成熟，不成熟就没法学吗？等待你的结果只有两种：

  • 去探究新的领域，自行整理学习新内容
  • 等到行业体系成熟，变成红海之后接受体系化培训

真正厉害的人在企业里拿高薪，不能咬死他们就不想要分享。综合多个因素：

  • 企业信息的保密要求
  • 工作繁忙导致没有时间流出来给自己整理知识
  • 整理体系化教学十分消耗精力，甚至还吃力不讨好

而如果他们真的最终整理出来一套內容，和培训机构出的绝对不一样。但这种培训收割与培训机构收割的性质滑动往往只在一念之间，真真假假难以分清。依然回到最开始提到的，关于 IT 人的技术分享习惯，一本精心整理的书和随手录的视频课程差异，不言自明。

并非所有人都真心热爱计算机，但计算机行业的高薪有目共睹，这吸引了太多本身不喜欢，而且不会干一行爱一行的人集中到这个方向。这没什么可耻的，但对于高薪的欲望，与对技术难度的低估，双双被培训机构利用。涌入的人越多，行业越内卷，机构越多，于是整个行业越来越糟糕。

接着 Agent 来到，把所有技术深度不足的人一扫而空，或者我们说的更直接一点：一脚踢死。同样的，嵌入式开发、网络安全行业都照着这个流程循环着。

08-回到硬件¶

那为什么回到硬件，接着上个文章没有说清楚的內容。其实部分传统安全人都认为，车联网安全就是把机器从电脑转移到了汽车终端上渗透，硬件逆向也可以让 Agent 来逆向，只有 Agent 进场，一切问题都能解决。

在假设说法是正确的基础上，我们在招聘网站上搜索一下有关于物联网、车联网等岗位的要求，其中

  1. 大幅度出现的关键词是 ISO 20262、ISO/SAE 21434、GB 44495、UN R155 R156，TARA。这些內容随便拉出来一项，传统安全人员谁能知道这五个名词中谁代表什么。
  2. 大部分岗位要求有数年的车联网、嵌入式，甚至是安全相关的经验，什么渗透测试人员有这些知识？

除此之外我们还有一些别的问题，在招聘网站上搜索，不难发现这些岗位的薪水都很高，往往比普通的渗透测试或者蓝队岗位薪水还多得多。如果这些岗位的工作其实根本一样，都能用 Agent 解决，那为什么大家还不转岗，难道是恪守清贫吗？

目前为止，暂时解释了为什么渗透测试人员不会直接转到硬件渗透岗上。那么接下来，你可能会问，渗透测试人员只要只要学习关于硬件的相关知识，不就能胜任了吗？这个问题本身存在几个悖论：

第一：车联网与硬件的知识体量与难度可能超乎你的想象，这里并不是说硬件一定比渗透难，但至少没简单到是人是鬼路过都能踹两脚。

第二：如果你要雇一个即插即用来硬件安全渗透的安全人员，那么你要雇一个拥有丰富经验的渗透测试人员，还是入门的渗透测试人员呢？很明显是前者对吧。那么，如果我拥有丰富的渗透测试经验，在本行当里就混的风生水起，为什么要刻意跳出自己的舒适圈，学习一大堆和自己原来內容完全不相干的硬件知识。有这时间，精进一把自己原来的渗透能力，或者多挖几个漏洞赚钱的速度，都比这来的有效率多了。

额，那么首先，传统安全人员没法直接进入硬件安全，学习安全又极没有性价比。那么让原本的硬件人员来学习安全测试不行吗？

这个问题的答案也是相应的，硬件入安全与安全入硬件都一样隔行如隔山。并且同样的，培养的这部分谁来出。如果我培养出来了一个复合型人才，结果跑了呢？

如果是硬件，这方面还稍微好一点，因为至少嵌入式开发与设计的资料生态非常成熟，在这方面的人数还比较多，在饱和情况下，还有部分人往安全逸散。

如果来到车联网，更是灾难中的灾难。资料缺乏，本身了解车联网的人数就少。而对车联网了解最深的这帮人，一般是硕博——车企中的骨干，车联网研发的核心人才。来自同样的悖论，并且基础上还多增加了一条。

  • 安全的学习成本太高
  • 本身研发车联网的工资就比同级别的安全岗位薪水还高，为何要离开舒适区
  • 企业也不会把这样的核心人员转到安全测试岗位上，如果你走了，那车联网研发的萝卜坑谁来填

死结彻底出现了，硬件安全的岗位很少，但能够胜任甚至待培养的人数更少之又少。

尽管这个理由并不完整，因为并没有花时间完善思考过这里的逻辑是否完全闭合。而这也正是本文的标题“风口还是赌博”的原因。

高考结束，没有任何实际根据，我选了合工大。

大一，没有任何实际考证，我专向了网安。

现在，又再次缺乏考证地，我决定回头硬件。

我不确定我是否看到了所谓的风口，我只是想最后再寻找一次，是否还有属于自己的一片蓝海探索成长，只不过目前看来，这更像又是一次赌博。

还有一些其他的，网络安全被认为是最不看重学历，只看实战能力的行业。但问题是，我作为211的学生，学历本来应该是我的优势啊，为什么要丢掉自己的优势去和别人的长处比较呢？

在网络安全趟了一年半浑水之后，我已经理解了什么是环境，编译，驱动，操作系统，寄存器，串行并行，等等等等，硬件至少已经没有那么 PTSD 了，还有机会么。

合工大的食堂很好，多吃一顿饭吧，我也想喝酒了。
