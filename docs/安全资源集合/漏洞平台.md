# 漏洞平台

## 漏洞库

- [Exploit-DB](https://www.exploit-db.com/)：公开 EXP 与 PoC 的最大集合，按 CVE 和平台检索
- [Rapid7 DB](https://www.rapid7.com/db/)：Rapid7 的漏洞库，与 Metasploit 模块对应
- [Vulnerability Lab](https://www.vulnerability-lab.com/)：偏厂商与产品维度的漏洞披露归档
