## pwn.college {#pwn-college}

网址：[pwn.college](https://pwn.college/)

### 平台背景

这是亚利桑那州立大学（ASU）的安全课程，2018 年开课，2020 年免费开放，目前已有五万余人至少完成过一道题。它不是商业产品，而是教学基础设施，因此设计逻辑与前几个平台都不同。

### 内容组织

平台的核心是腰带（belt）制度，形式上类似段位：白带、橙带、黄带、绿带、蓝带，顺序考核，不可跳级。注册后即为白带，每完成一个道场（dojo）升一级。升到蓝带后，主办方会实际寄出一条绣有 pwn.college 字样的腰带，目前仅寄送至蓝带及以上。

道场是按主题划分的题库。前面四个为入门道场，分别介绍平台用法、Linux 操作、计算机底层原理，以及如何「滥用」合法程序完成越权。此后为四条主线：

| 腰带 | 道场 | 内容 | 题量 |
|---|---|---|---|
| 橙带 | Intro to Cybersecurity | 安全全景与基础利用 | 183 |
| 黄带 | Program Security | shellcode、栈溢出、ROP、堆 | 159 |
| 绿带 | System Security | 沙箱逃逸、竞态条件、内核、CPU 侧信道 | 93 |
| 蓝带 | Software Exploitation | 格式化字符串、file struct、利用原语、内核利用 | 90 |

### 教学设计

难度经过刻意调整。大量题目成对出现：easy 版本提供源码与调试输出，hard 版本移除源码并关闭提示，要求学习者自行完成逆向。同一知识点先在受控条件下练习，再在无提示条件下复现。这种设计在其他平台中较为少见。

shellcode 关卡还设置了字节数限制，仅提供 12 字节或 18 字节的空间，部分关卡禁止使用特定系统调用。其目的不是提高难度，而是让学习者理解在空间受限时如何构造可用的攻击载荷。

浏览器内自带终端与编辑器，无需配置环境，提交 flag 后立即判分。这一点明显优于 OST2。

### 特点与局限

体量是其主要门槛。四条腰带合计 525 题，加上前置道场接近 900 题。官方课程要求学生每周投入 20 至 30 小时；按业余时间估算，至黄带约需 150 至 300 小时，至蓝带需 500 小时以上。中段容易产生疲劳。

另需注意，注册时即须同意「不公开题解」的约定。因此在互联网上无法检索到答案，卡住时只能通过官方 Discord 提问。这一约定保护了教学效果，但对自学者构成额外负担。

### 适用阶段

掌握 C 语言与 Linux 基本操作之后。它是从「会写程序」过渡到「会攻击程序」之间最完整的一座桥。

## OST2 {#ost2}

网址：[p.ost2.fyi](https://p.ost2.fyi/)

### 平台背景

OST2 是最容易被误解的一个平台，需要先说明其来历。项目由 Xeno Kovah 发起。他早年在 MITRE 从事 Windows 内核恶意代码检测，后进入 Apple 参与 T2 与 M1 芯片的安全启动设计，2020 年离职后全职投入该项目。他从 2011 年开始免费录制安全课程，那批内容发布在 opensecuritytraining.info 上，称为 OST1。

OST1 后来逐步停止更新，2016 年之后基本没有新增内容。2021 年，同一批人迁移至现代教学平台 Open edX，将课程重新制作并重新发布，称为 OST2，即目前访问的 p.ost2.fyi。旧站点现在只保留一个镜像页，页面顶部注明应前往新站学习。

这一点在教学材料的引用中经常出错。互联网上大量推荐内容指向的仍是 OST1 的课程，例如 The Life of Binaries、Rootkits、Intro to Exploitation。这些课程在 OST2 上尚未提供，只能通过旧站镜像观看，画质与平台均为十年前的形态。

### 内容组织

平台目前包含 31 个专题，单个专题时长 2 至 32 小时不等，合计一百余小时视频。内容按系列编号，前缀含义如下：

| 前缀 | 全称 | 内容 |
|---|---|---|
| Arch | Architecture | 体系结构，CPU 与操作系统的工作原理 |
| Vulns | Vulnerabilities | 漏洞，C 语言实现缺陷的分类 |
| Exp | Exploitation | 利用，将漏洞转化为可执行的攻击 |
| RE | Reverse Engineering | 逆向，将编译后的程序还原为可读形式 |
| Dbg | Debuggers | 调试器，使程序暂停并观察内存状态 |
| TC | Trusted Computing | 可信计算，主板上的安全芯片 |
| HW | Hardware | 硬件，直接读取主板存储芯片 |
| Fuzz | Fuzzing | 模糊测试，自动生成输入触发崩溃 |

编号也大致对应难度：1xxx 为入门，2xxx 为中级，3xxx 为进阶，4xxx 为高难或专项。

### 主要课程

Arch1001 x86-64 汇编，10 小时。讲解如何阅读汇编代码，即 CPU 直接执行的指令。后续所有漏洞分析与逆向工作都以这项能力为基础。

Arch2001 x86-64 操作系统内部，18 小时，是该平台的代表性课程。内容涵盖内存分页（paging）、用户态与内核态的隔离（ring3 与 ring0）、中断与系统调用的发生过程。完成之后可以理解「提权」的实际含义，以及内核漏洞为何具有较高危害。

Arch4001、Arch4021、Arch4031，分别为 Intel 固件（firmware）攻防、UEFI 入门与 coreboot 入门。固件是计算机通电后执行的第一段程序，层级低于操作系统。攻击固件的价值在于可以长期驻留，重装系统无法清除。

Vulns1001 与 Vulns1002，15 小时与 24 小时。课程不涉及靶机，而是讲解 C 语言层面的错误分类：数组越界、整数溢出、释放后使用、格式化字符串。这是后续所有利用课程的基础。

Exp4011，16 小时。以一个真实的 Windows 内核漏洞（KTM 中的竞态条件与释放后使用）为例，完整走一遍从分析到利用的过程。需要注意，这是 OST2 目前唯一上线的利用类课程，Exp 系列其余编号在官网上仍为空白。

Dbg 系列，共 9 门，包含 WinDbg 三阶、GDB、IDA、Ghidra、Binary Ninja、Simics 与 HyperDbg。调试器的作用是使程序暂停执行，并观察其内存与寄存器状态，是漏洞研究中的常用工具。

TC1101 至 TC1103 与 TC2202，TPM 系列四门。TPM（可信平台模块，Trusted Platform Module）是焊接在主板上的安全芯片，用于存储密钥并校验启动过程是否被篡改。Windows 的 BitLocker 磁盘加密与 Windows Hello 指纹登录均依赖该芯片。这四门课程分别讲解其使用方法、Python 调用方式以及攻击面。

此外，HW1101 使用 SPI 编程器直接读取主板 flash 芯片中的固件；Fuzz1001 使用 AFL++ 进行白盒模糊测试；BT2222 讲解蓝牙设备的侦察方法。

### 学习路径

平台提供一张学习路径图，将课程按方向编排为七条线路：蓝牙、固件安全、逆向与恶意代码分析、安全软件设计、系统安全、漏洞挖掘与利用、Windows 安全。每条线路标注了单门课程的预计时长与前置知识要求。

需要注意图中的空白方框。这些方框标注为「Future / Instructors Wanted」，表示该课程尚未录制、正在招募讲师。阅读路径图时应区分已经上线的课程与规划中的课程。

### 教学形式

课程由视频、PDF 讲义与实验手册组成，学习进度自行安排，没有开课时间。实验大多需要自行搭建虚拟机，其中 Arch2001 要求安装 Windows 与 Visual Studio 2019。2026 年新增的课程（例如 Arch1901「从零实现一个 QEMU 模拟器」）开始提供浏览器内的托管实验环境，早期课程则没有。

平台不提供自动判题，学习效果完全依赖自觉。这是它与 pwn.college 最主要的差别：前者讲透原理但不做检查，后者几乎不讲解但每道题都有判分。

### 费用

全部免费。运营方为美国注册的非营利机构（501(c)(3)），依靠赞助与捐赠维持，赞助方包括 TCG（TPM 系列课程的来源）、Binarly、Hex-Rays 等。平台不设付费墙，未登录状态下也可观看课程。

### 特点与局限

课程录制时间较早，Arch1001 仍为 2021 年版本；讲授节奏较慢，形式为讲师在黑板前逐条讲解，通常需要 1.5 至 2 倍速播放。实验环境搭建对初学者构成明显障碍。平台没有题目与评分，长时间观看容易失去焦点。

### 适用阶段

当学习者不再满足于「知道如何攻击」、而希望理解「为何如此」时。它补充的是 pwn.college 之前的那一层基础。
