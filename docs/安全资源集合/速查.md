# 速查

## 命令与提权

- [GTFOBins](https://gtfobins.org)：Linux 提权大全。查某个常见命令在什么条件下可以拿来提权、怎么用
- [LOLBAS](https://lolbas-project.github.io/)：Windows 版的对应物，系统自带程序被滥用的情况
- [HackTricks](https://hacktricks.wiki/en/)：攻防技巧的百科，遇到没见过的场景先在这里搜
- [ExplainShell](https://explainshell.com/)：粘贴一条命令，逐段解释每个参数的含义
- [tldr](https://tldr.sh/)：只给常用示例的简化手册，比 man 快
- [cheat.sh](https://cheat.sh/)：终端里执行 `curl cheat.sh/命令` 直接查速查表

## Shell 与系统调用

- [Bash 官方手册](https://www.gnu.org/software/bash/manual/bash.html)：Shell Syntax → Quoting → Expansions 三章
- [POSIX Shell Command Language](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html)
- [syscalls.mebeim.net](https://syscalls.mebeim.net/)：按架构整理，标注寄存器与参数顺序
- [Linux syscall table](https://filippo.io/linux-syscall-table/)：官方编号对照
- [man7.org](https://man7.org/linux/man-pages/)：man 手册在线版，带搜索
- [Linux man-pages 项目](https://www.kernel.org/doc/man-pages/)：上游手册源
- [POSIX 标准](https://pubs.opengroup.org/onlinepubs/9699919799/)
- [CreateProcess](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessa)：Windows 的进程创建接口

- Python：[subprocess](https://docs.python.org/3/library/subprocess.html)
- Node.js：[child_process](https://nodejs.org/api/child_process.html)

- Go：[os/exec](https://pkg.go.dev/os/exec)
- Ruby：[Kernel](https://docs.ruby-lang.org/en/master/Kernel.html)
