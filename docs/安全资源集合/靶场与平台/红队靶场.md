## HackTheBox {#hackthebox}

网址：[hackthebox.com](https://www.hackthebox.com/)

HTB 由 HTB-Academy 与 HTB-Labs 组成，属于两套独立订阅，互不包含。

### Labs

Labs 是 HTB 的主站，以靶机实战为特点，左侧为站点功能。

- Session：赛季。维持 3-4 个月的长期打榜，按照解出机器 flag 的数量分为 4 个层级：Silver、Ruby、Platinum、Holo。会挂上个人历史，也会赠送部分优惠
- Starting Point：面向初学者的数个 easy 靶机，分 3 个层次（tier0、tier1、tier2），带领新手入门
- Machine：机器是 HTB 的当家特色，现有所有靶机集合
  - 按难度分 5 层：very easy、easy、medium、hard、insane
  - 按状态 2 类：服役、退役
- Sherlocks：夏洛克，面向蓝队的靶机
  - 涵盖取证、恶意软件分析等数个蓝队技能
  - 难度分类、状态分类均与 Machine 相同
- Challenges：CTF 赛题集合
  - 按内容：在传统 5 个 CTF 分类基础上，还有 OSINT、ICS、Hardware、Quantum 等新类型
- Tracks：收录了数个靶机而形成的一条推荐练习路线
- Pro Labs：大型实验室，与 Machine 的体量差别极大，通常是一个大型仿真企业内网环境，完成时间是一台 Machine 的数倍
- Fortresses：要塞。由企业和 HTB 合作推出的大型实验室，部分难度低于 Pro Labs，但体量仍然恐怖

当靶机处于服役状态时，全部用户都可免费游玩机器，每个类型约 20 台。每一周或两周时间，官方会下架一台机器，同时上架一台新机器，此时被替换的机器改为退役状态。服役期间，靶机全网禁止公开题解。

机器进入退役状态后，部分机器可以免费游玩，但大多数需要升级到 VIP+ 访问。

### HTB Academy

HTB-Academy 是诞生在 HTB-Labs 后的教学部分。

每个类型知识点被整理为一个模组（module），形态为文字教材加实验，每个小节都会附有实践题目。部分模块结束时会有技能评估（Skills Assessment）小节。

对于系统学习知识点和寻找阅读材料，HTB-Academy 是一个很好的选择，大部分模组免费，或者 10 cube（HTB 内的货币）兑换，后返还。在不深入学习高级模组前，cube 尚且可以免费白嫖。

### 认证

HTB-CPTS 与 OSCP 的比较是近年讨论较多的话题。

OSCP 是 OffSec 推出的渗透测试认证，一直被视为渗透测试的行业通行证。

- 认证测试要求：24 小时内，渗透 3 台靶机、1 组域环境，结束后 24 小时内输出一份测试报告，70 分通过。
- 具有两次考试机会
- 费用：约为 $1700

CPTS 是 HackTheBox 推出的渗透测试认证，近年来热度逐渐攀升。

- 认证测试要求：完成前置 HTB-Academy CPTS 路径的全部内容。正式考试为期 10 天，渗透一次仿真企业内网约 8 台主机，通过线 12/14 flag。同时需要输出一份英文商业级渗透测试报告。
- 具有两次考试机会
- 费用：门票 $210，同时学习前置课程需要的费用因人而异

除此之外，HTB 也有其他认证，方向价格都不等，其中 CPTS 认证只是热度最高的一个。

### 费用

需要注意，Labs 与 Academy 属于两套独立订阅，互不包含。截至 2026 年 11 月，VIP+ 为每月 $25（2025 年 10 月取消了原 $14 档），HTB PRO 为每月 $49（2026 年 9 月上线，包含 10 个 Pro Lab），Academy 从学生档每月 $10 至 Platinum 每月 $125。全部订阅一年可超过 $1000。

### 特点与局限

平台的主要问题是难度曲线陡峭。Easy 机器对于新手来说并不是真的 "Easy"，不少学习者的第一台 Easy 靶机会卡上一整天。退休机制也意味着排行榜只反映近几个月的活跃度，且老机器的技术栈可能已经过时。

HTB Academy 的课程部分见[课程](../课程.md)。

## TryHackMe {#tryhackme}

网址：[tryhackme.com](https://tryhackme.com/)

### 平台形态

如果 OverTheWire 是提供一台主机由学习者自行摸索，TryHackMe 则是提供一位讲解者逐步引导。平台的基本单位称为房间（room），一个房间对应一个小专题，耗时约半小时至两小时。房间页面左侧为讲解内容，右侧为一台云主机或网页靶场。阅读一段讲解后会出现一道问题，答案位于右侧的机器中，填入后即完成该节。

这种「讲解—操作—验证」的循环是平台的核心设计，也是它区别于纯题库的地方。

### 内容结构

房间可以单独完成，也可以按路径（path）顺序推进。目前平台共提供 18 条路径，主线排列如下：

| 路径 | 内容 |
|---|---|
| Pre Security | 面向无底层基础的读者，讲解网络、Linux 与 Web 的基本概念 |
| Cyber Security 101 | 覆盖主要安全方向 |
| Jr Penetration Tester | 渗透测试入门，进入靶机演练 |
| Offensive Pentesting | 进阶内容，接近 OSCP 风格 |

此外还有 Red Teaming、SOC Level 1/2（蓝队方向）、Web、AWS 与 Azure 等分支。

### 接入方式

平台提供两种接入靶机的方式。第一种是 AttackBox，即浏览器内直接启动的云主机，无需本地配置，免费用户每日可用 1 小时。需要注意，官方文档目前将其描述为 Ubuntu 而非 Kali，尽管大量既有文章仍沿用 Kali 的说法。第二种是在本地安装 Kali，通过 OpenVPN 连接，这种方式不消耗 AttackBox 时长，是免费用户的主要选择。

### 认证与费用

平台目前提供 8 项认证，其中最常被提及的是 PT1（渗透测试一级）。该考试为 48 小时窗口，Web 占 60%、网络占 20%、域环境占 20%，完成后需提交报告，报告由 AI 评分，费用为 $349。这类认证在招聘环节的认可度有限，招聘方通常仍以 OSCP 为准，但其门槛与价格较低，适合作为练习目标。

免费层已覆盖相当数量的房间，但优质路径基本需要订阅。Premium 约为每月 17–18 美元；2026 年 6 月新增的 MAX 档为每月 29–31 美元，将进阶路径与云方向内容划入其中。学生年付可再享受八折。

### 特点与局限

平台的教学引导极为细致，每一步都会给出应当执行的命令。这种设计降低了入门门槛，但也容易造成「已经掌握」的错觉。不少学习者完成整条路径后，面对一台未见过的靶机仍不知从何入手。这不是平台的缺陷，而是此类教学法的固有代价。相对有效的做法是，每完成一个房间后合上教程，用自己的语言复述完整的攻击链；无法复述即说明尚未掌握。

### 适用阶段

第一至第三个月，用于建立对安全各方向的整体认识。

## OverTheWire {#overthewire}

网址：[overthewire.org](https://overthewire.org/wargames/)

### 平台形态

OverTheWire 是运行时间最长的闯关类平台之一，界面与内容组织方式仍保留着二十年前互联网的形态。平台不设注册、积分与视频讲解，访问者看到的只有一行提示：使用给定的用户名与密码通过 SSH 登录指定主机。

与 CTF 的区别在于，平台提供的不是一道题的附件，而是一台可交互的 Linux 主机。我们需要在这台主机上寻找下一关用户的密码，使用该密码登录下一关，如此往复。密码本身即为 flag，因此关卡答案在互联网上广泛存在，这一点在后文讨论局限时还会提到。

### 内容结构

Bandit 是所有关卡中最适合入门的一组，共 34 关，从 SSH 的基本用法一直覆盖到 cron 任务与 setuid 文件的查找。对于仅掌握 `cd` 与 `ls` 的学习者，完成 Bandit 后即可具备后续学习所需的命令行基础。这也是目前成本最低的 Linux 入门材料。

Bandit 之外，平台还提供若干难度递增的关卡集：

| 关卡集 | 主题 | 关卡数 |
|---|---|---|
| Bandit | Linux 命令行 | 34 |
| Natas | 服务端 Web（浏览器内完成，不使用 SSH） | 35 |
| Krypton | 古典密码（凯撒、维吉尼亚、频率分析） | 8 |
| Leviathan | 逆向入门 | 8 |
| Narnia | 基础二进制漏洞 | 10 |
| Behemoth、Utumno、Maze | 逐级递进的二进制利用 | 9 / 10 / 9 |
| Vortex、Drifter | 综合题 | 27 / 16 |
| Manpage | 阅读 C 源码寻找漏洞 | 7 |

### 特点与局限

该平台的优势在于结构干净。没有积分体系，也没有成就设计，学习者唯一能够自欺的方式是搜索答案；而在此平台上搜索答案的代价尤其高，因为密码即 flag，搜索一次即跳过一关，不会留下任何训练痕迹。

局限主要体现在内容年代。二进制相关关卡仍为 32 位程序，依赖十余年前的 libc 版本，无法在本机复现，只能连接平台服务器完成。平台几乎不提供讲解，每一关只给出一句提示与若干「可能用得上的命令」，卡住时需要自行查阅 man page 或搜索他人的解题记录。截至 2026 年，平台仍可正常访问，代码仓库偶有提交，但基本不再新增关卡。

### 适用阶段

学习的第一周。完成 Bandit 之后，再考虑其他平台。
