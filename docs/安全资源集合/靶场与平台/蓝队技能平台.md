# 蓝队技能平台

## 平台

- [Let's Defend](https://letsdefend.io/)：蓝队 / SOC 应急模拟
- [CyberDefenders](https://cyberdefenders.org/)：蓝队取证，流量与内存分析题
- [Blue Team Labs Online](https://blueteamlabs.online/)：真实取证镜像练习

## 检测与演练

- [SigmaHQ](https://github.com/SigmaHQ/sigma)：检测规则库
- [sysmon-modular](https://github.com/olafhartong/sysmon-modular)：Sysmon 配置模板，可直接改
- [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team)：按 ATT&CK 编号模拟攻击，用来验证日志能不能抓到

## 课程与路径

常见的进阶顺序：

1. Windows Fundamentals
2. Windows Event Logs and Finding Evil
3. Intro to Threat Hunting
4. SOC Analyst Path
5. CDSA

- [SANS](https://www.sans.org/)：SEC504、SEC511，预算不够就看白皮书和海报

## 流量与样本

- [Malware-Traffic-Analysis](https://www.malware-traffic-analysis.net/)：恶意软件流量样本加练习题
