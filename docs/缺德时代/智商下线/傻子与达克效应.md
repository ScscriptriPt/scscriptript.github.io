# 傻子与达克效应

很多时候，对于你不完全了解实情，甚至是你已经比较熟悉的领域，也不要随意发表不恰当的言论，尤其是你和人面对面交锋时。当你被现实戳破时，真的会让你自己显得非常蠢。

事情经过是这样：在2026年秋季十月份，我的大创进行了接近一年的时间。有一天，我的项目指导老师说，项目经费到了，需要报销的要赶紧报销，不然十月份底就要回收了。此前，我一直不知道自己的项目原来还有经费可以报销，因此使用都是收着用的，大约花了170元。而项目的报销金额上限是2000元。

我在想，这么多的钱没有用完，那就浪费了。我先往账号上充值了500块钱。用着用着又充了400，150。在暑假期间，我给自己的实验室同学报销过一次token，我知道，学校报销token是要看你是否真的用完了的。而且清点过程非常麻烦。但是和这次不一样的地方是：我这个项目赛道是产教融合。也就是说，经费拨款方不是学校，而是企业。指导老师发给我一份文件夹，里面有三样报销需要的材料：付款记录合集、发票、企业提供服务证明。而这第三张搞不到。指导老师让我去问了一个财务老师，沟通中，我明确说了使用量会和充值量对不上的情况。再三确认下，老师告诉我，可以截API官网的支付记录截图当作证明。因此，我可以先往账号中把金额充进去先报了，之后慢慢蹬蹬完。

发现了么，这样的报销，是不需要提供详细的用量证明的，核心原因是我的大创项目走的是产教融合赛道，不是创新创业赛道，直接对应人是企业不是学校。财务走的是企业，不是学校，而企业根本不在乎这点小事，这点事情在他们眼里几乎是心知肚明的。

回到宿舍，我向我的一个同学分享我的担忧，我充了这么多钱，如果报不下来，那就很难堪了：你的账户里躺着1000多块余额是件很恐怖的事啊。此时，主人公终于出场了，旁边的人笑着，不管是这个家伙管理不好面部表情，还是情商低的发指，且不论他刻意听着我们的对话还自顾自插话，他说：没有用掉的token是不能报销的，他们只能报用掉的。我当作没有听到，继续和我的同学讲话。

原因具体是个什么情况，我上面已经说的很明白了。而他的假设有两个：

1. 我大创走的是创新创业赛道
2. 我不知道token的报销流程

事情究竟幽默在哪些地方，不言自明。所以，在开口前思量，不然，在别人眼里你就是个纯粹的傻子，还自以为聪明
