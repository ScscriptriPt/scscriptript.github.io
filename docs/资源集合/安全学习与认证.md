## 证书

部分证书收费较高，前几个大学能加分。后面因为评价体系不同，不能加分。

大学期间可考：

1. [Google 网络安全证书](https://grow.google/certificates/cybersecurity/)
2. [NISP](https://www.nisp.org.cn/)：国家信息安全水平考试，二级可免试换领 CISP
3. [CISP-PTE](https://www.itsec.gov.cn/)：注册渗透测试工程师，中国信息安全测评中心发证
4. [HackTheBox 系列证书](https://academy.hackthebox.com/)：CBBH、CDSA 等
5. [TryHackMe 系列证书](https://tryhackme.com/)
6. [CRTO / CRTM](https://www.zeropointsecurity.co.uk/)：红队实战方向，近几年红队热度就是它们推起来的

工作可考（资金和经验双重原因）：

1. [CISSP](https://www.isc2.org/certifications/cissp)
2. [OSCP / OSEP](https://www.offsec.com/)
