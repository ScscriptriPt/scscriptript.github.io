# 计算机自学与课程

学习路线、经典课程与书籍、社区。

## 学习路线

- [CS 自学指南](https://csdiy.wiki/)
- [roadmap.sh](https://roadmap.sh/)：和自学指南站一起用
- [labuladong 的 Agent 学习路径](https://labuladong.online/zh/roadmap/agent/)：可以作为参考，但很多都收费，参考就行了，别真的花钱

## 课程与书籍

- [CSAPP 深入理解计算机系统](https://hansimov.gitbook.io/csapp)：顶顶大名
- [人月神话 中文版](https://cactus-proj.github.io/The-Mythical-Man-Month-zh/)
- [Linux C 编程一站式学习](https://www.bookstack.cn/read/linux-c/menu.md)：书栈网
- [Coursera](https://www.coursera.org/)：很好的集成课程网站，很多都免费
- Just For Fun：Linus自传，了解我们是什么样子
- [鸟哥的Linux私房菜](https://github.com/inityun/vbird_linux_gitbook)：：通俗的Linux书籍，但通俗≠上瘾般的喜欢

## 社区与问答

- [GitHub](https://github.com/)：不必多言
- [Stack Overflow](https://stackoverflow.com/)：栈溢出
- [菜鸟教程](https://www.runoob.com/)
- [上海交通大学学生生存手册](https://survivesjtu.gitbook.io/survivesjtumanual)
- [freecloud.dev](https://blog.freecloud.dev/)：我喜欢的一个 B 站 UP，前字节，清华，很厉害的软件工程师
