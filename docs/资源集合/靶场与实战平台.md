# 靶场与实战平台

打靶练手的地方。在线平台多按订阅收费，自建靶场免费，按预算和方向选择。

## 在线平台

- [HackTheBox](https://www.hackthebox.com/)：但是最近的价格变得非常不合理，2026 年暑期开始
- [HackTheBox Academy](https://academy.hackthebox.com/)：HTB 的体系化学习分支，课程与靶机一体
- [TryHackMe](https://tryhackme.com/)：新手友好，路线清晰
- [PentesterLab](https://pentesterlab.com/)：小练习形式，Web 方向不错
- [PortSwigger Web Security Academy](https://portswigger.net/web-security)：免费，Web 安全的事实标准教材
- [Let's Defend](https://letsdefend.io/)：蓝队 / SOC 应急模拟
- [CyberDefenders](https://cyberdefenders.org/)：蓝队取证，流量与内存分析题
- [CyberBit](https://www.cyberbit.com/)
- [SimSpace](https://www.simspace.com/)：企业级网络靶场，看看就好，个人玩不起
- [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/)：故意漏洞百出的电商站，Docker 一键起
